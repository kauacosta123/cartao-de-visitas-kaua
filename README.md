# Cartão de Visitas Digital

Cartão de visitas digital no estilo Linktree: página com foto, bio e links para GitHub, LinkedIn e portfólio. Projeto desenvolvido como atividade para a vaga de Estágio em Desenvolvimento.

## Como executar

1. Baixe o projeto de uma das formas:
   - Clonando o repositório:
     ```bash
     git clone https://github.com/kauacosta123/cartao-de-visitas-kaua.git
     ```
   - Ou clicando em **Code > Download ZIP** no GitHub e extraindo a pasta.

2. Abra a pasta do projeto e dê dois cliques no arquivo `index.html`.

Não é necessário instalar nada: o site roda direto no navegador.

## Tecnologias

Optei por HTML, CSS e JavaScript puros, mantendo o projeto leve e sem dependências.

- **HTML:** utilizado para criar a estrutura do projeto, com tags semânticas (`main`, `nav`).
- **CSS:** utilizado para estilizar e posicionar os elementos. Usei variáveis para facilitar a manutenção e a troca de tema, Flexbox para o layout e a metodologia BEM para nomear as classes.
- **JavaScript:** utilizado para dar funcionalidade ao botão de alternância de tema.

## Funcionalidades

- Layout responsivo para celular e desktop
- Alternância entre tema claro e escuro
- Links para GitHub, LinkedIn e portfólio
